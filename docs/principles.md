# Principles

These are the engineering principles that guide how Auto-Guardable is built. They may evolve as the project matures, but they should always support the Constitution and Vision.

## Engineering Principles

- Simplicity over cleverness.
- Explicit over implicit.
- Interfaces before implementations.
- Prefer composition over inheritance.
- Fail safely.
- Testability is a feature.
- Small, reviewable pull requests are preferred.
- Documentation precedes implementation.
- Architecture Decision Records should capture significant technical decisions.
- Refactoring is continuous, not optional.

## Product Principles

- Reliability is a feature.
- Latency matters.
- Offline capability matters.
- User trust is earned.
- Privacy is part of usability.
- De-escalation is a core product behavior, not an afterthought.
